# Indimi (i18n) — Ikinyarwanda · English · Kiswahili · Français

Nta API cyangwa model y'ubuhinduzi ikoreshwa. Byose bishingiye ku **nkoranyamagambo zawe** (JSON).

## Uko bikora

- Ururimi ruhitwamo n'agashushanyo k'isi muri Header (no muri menu yo ku ruhande kuri telefone). Rubikwa muri cookie `lang` + localStorage. Ikinyarwanda ni rwo rw'ibanze.
- Inyandiko zose z'urubuga muri pages na components zikoresha `t("...")`. **Urufunguzo ni inyandiko y'umwimerere** (nk'uko iri mu code), urugero `t("Soma byinshi")`.
- Inkoranyamagambo ziri muri `src/i18n/locales/`:
  - `rw.json` — Ikinyarwanda (urufunguzo rwa kera rwa `nav.home`, ...; amagambo asanzwe asigara mu mwimerere)
  - `en.json`, `sw.json`, `fr.json` — `{ "umwimerere": "ubuhinduzi" }`
- Iyo ubuhinduzi budahari mu rurimi rwahisemo, hagaragara umwimerere (urubuga ntirwangirika).

## Kongeramo amagambo (vocabulaires)

1. Fungura `src/i18n/locales/sw.json` (cyangwa `en` / `fr`) hanyuma wongereho:
   ```json
   "Soma byinshi": "Soma zaidi"
   ```
2. Amagambo arimo ibihinduka akoresha `{izina}`; bigomba kuguma ari bimwe mu buhinduzi:
   ```json
   "Ufite {count} inkuru": "Una hadithi {count}"
   ```
   ```jsx
   t("Ufite {count} inkuru", { count: stories.length })
   ```
3. Kureba ibisigaye byose: `npm run i18n:check`. Iremeza ko `{placeholders}` zingana, ikandika amagambo ataraboneka muri `i18n-todo/<ururimi>.json` (wuzuza `""` hanyuma ubishyire muri `locales/`). Mu cyongereza, hagaragazwa gusa amagambo asa n'Ikinyarwanda/Igifaransa.

## Kwandika code nshya

```jsx
import { useI18n } from "@/i18n/I18nProvider";

export default function Page() {
  const { t, lang } = useI18n();
  return <h1>{t("Muraho neza")}</h1>;
}
```
Inyandiko zo hanze ya component (urugero `const TABS = ["Byose", ...]` hejuru mu rugero) ntizihindurwa na `t()` zonyine: shyiramo `t(label)` aho zerekanwa (`{t(tab)}`), maze wongere `t("Byose")` muri dictionary (cyangwa wandike `t("Byose")` mu gice cyo kwerekana kugira ngo `npm run i18n:check` ibibone).

## Ururimi rushya

Ongeraho muri `src/i18n/config.js` (`LANGUAGES`), ukore `src/i18n/locales/<code>.json`, hanyuma wongere import muri `src/i18n/I18nProvider.js` (`dictionaries`) no muri `scripts/i18n-check.mjs` (`LANGS`).

## Ibiva muri database (inkuru, imitwe)

Inkoranyamagambo ntishobora guhindura inkuru zose ziva muri database. Niba ushaka inkuru mu ndimi nyinshi, bika ubuhinduzi muri document ubwayo (`head_en`, `story_sw`, cyangwa `translations: { fr: { head, story } }`) hanyuma ukoreshe `l(post, "head")` / `l(post, "story")` (iva muri `useI18n()`); iyo ubuhinduzi budahari hakoreshwa umwimerere. Ibi bimaze gushyirwa ku rupapuro rw'inkuru (`post/[id].js`).

## Ibyakuweho (Hugging Face)

`@huggingface/transformers`, `/api/translate*`, `src/lib/translator/`, `scripts/download-model.mjs`, `translate-all.mjs`, na `serverExternalPackages` byakuweho. Kuri Vercel/Firestore:
- Kora `npm install` kugira ngo `package-lock.json` ivugurure (nta Hugging Face ikiyirimo).
- Siba variables za `TRANSLATE_*` muri Vercel (niba warazishyizeho).
- Collection `translationCache` muri Firestore ushobora kuyisiba.

## Ibyo ugomba kumenya

- Ubu `t()` ihita ikora ku bikorwa bya kare (JSX, `placeholder`/`title`/`alt`/`aria-label`/`label`, `alert`/`confirm`/`setError`...). Amagambo ari muri constants zo hanze ya component, muri API routes, no mu mazina ya meta/SEO ya pages nyinshi ntahinduka.
- Ahari `useMemo`/`useCallback` zikoresha `t()`, shyiramo `t` mu dependency array kugira ngo ziheshe ururimi rushya.
- Nyuma yo gutangira, abahisemo ururimi rutari Ikinyarwanda bashobora kubona Ikinyarwanda akanya gato mbere y'uko page ihinduka.
